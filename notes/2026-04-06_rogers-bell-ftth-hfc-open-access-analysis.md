# Rogers vs Bell：加拿大宽带架构分析 + 开放光纤构想

## 内容

### 1) Rogers vs Bell：不同哲学

**Rogers（HFC / DOCSIS 模式）**
- Hybrid fiber-coax：光纤到街区/楼，最后一段走同轴电缆
- 靠 DOCSIS 持续升级速率
- 设计目标：最小化基础设施成本，最大化现有网络价值
- 结果：下行速度不错，上行弱，共享拥塞明显

**Bell（FTTH 模式）**
- 全程光纤到户
- 网络和电视全走 IP，无历史遗留同轴
- 结果：低延迟、对称速率、更面向未来

### 2) 为什么 Rogers "把光纤转回同轴"

光纤进楼 → 再转回同轴电缆——因为：
- 现有同轴布线已在位
- 有线电视生态仍依赖它
- 避免昂贵的户内重新布线

结论：技术上次优，经济上高效。

### 3) 为什么价格依然高（即使用的是旧技术）

不是技术问题，是市场结构：
- 竞争有限（Rogers / Bell / Telus）
- 加拿大基础设施成本高
- 监管没有强制真正的基础设施共享

### 4) 构想：光纤作为楼宇基础设施（开放接入）

提案：
- FTTH 写入建筑规范强制要求
- 光纤作为共管物业公共财产
- ISP 在电信机房接入
- 多运营商通过 WDM（波分复用）共用

本质 = "开放接入光纤网络"

**技术可行性：YES**（GPON / Active Ethernet / WDM 均已有实践）

**为何未被广泛推行：**
1. 成本责任：开发商不愿承担电信基础设施成本
2. ISP 阻力：失去"最后一公里"控制权，用户更易换供应商
3. 运营复杂性：谁维护？谁付升级费？多运营商协调
4. 监管惰性：CRTC 偏向渐进式改变而非结构性重组

### 5) Rogers 模式还有未来吗？

- 短期：仍可行（DOCSIS 升级，大量存量用户）
- 长期：逐步向 FTTH 转型，同轴慢慢退出
- 结论：没在"死"，但在压力下过渡中

### 6) 全球对比

接近构想的案例：
- 瑞典 → 市政开放光纤
- 新加坡 → 国家光纤基础设施
- 新西兰 → 基础设施与服务分离

共同因素：强政府干预

### 7) 核心洞察

> 这不是技术问题。更好的系统已经存在——但现有系统更有利可图。

是商业模式问题 + 激励结构问题 + 监管问题。

### 8) 实用行动指南

**选网络：**
- 优先选 FTTH（Bell 或同类）
- 如果被迫用 Rogers：预期上行弱、延迟高，性能取决于所在街区拥塞程度

**买房时检查：**
- 楼内是否有 FTTH？
- 是否有结构化光纤布线到户？

**政策层面：**
- 现实路径：推动批发接入规则，而非完整基础设施重组

---

**一句话总结：**
Rogers 是成本优化的历史遗产工程；Bell 是面向未来的设计；你的构想是理想系统——但被经济利益和激励结构阻挡，不是被技术阻挡。

## Bubble 的洞察

- 你对这个问题的思路走的是"为什么理想系统没有被实现"而不是"哪个套餐更便宜"——这是系统思维 vs 消费者思维的分野，你在用前者观察世界。
